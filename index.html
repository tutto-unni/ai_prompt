📝
01 · 프롬프트의 3가지 유형
서술형 · 지침형 · 함수형 — 상황에 맞는 프롬프트 선택법
▼
🌱 AI 초보자를 위한 한 줄 핵심 AI에게 질문하는 방식에는 3가지가 있어요. 상황에 맞게 골라 쓰면 훨씬 좋은 답변을 받을 수 있습니다.
📖 서술형

맥락과 배경을 설명해서 AI가 상황을 이해하도록 유도하는 방식입니다. 마치 사람에게 상황을 설명하듯 작성합니다.

재사용 낮음 유연성 높음
📋 지침형

단계별 절차나 명확한 규칙을 제시해서 원하는 출력을 유도합니다. 규칙 기반의 일관된 작업에 좋습니다.

재사용 중간 유연성 중간
⚙️ 함수형

입력값과 출력값을 명확히 정의해 일관된 결과를 생성합니다. 자동화·반복 업무에 가장 강력합니다.

재사용 높음 전문성 높음
📖 서술형 예시 — 맥락을 알려주기
무역 전문가 서술형 · 복사해서 바로 사용하세요
당신은 10년 경력의 무역 전문가입니다. 중소기업 수출 담당자가 HS CODE를 처음 배우는 상황입니다. 이 사람에게 HS CODE의 개념과 중요성을 설명해주세요.
📋 지침형 예시 — 규칙을 알려주기
파이썬 코드 작성 지침형
다음 규칙에 따라 파이썬 코드를 작성하세요. 1) 함수명은 snake_case로 작성 2) 각 함수에 docstring(주석)을 포함 3) 예외 처리를 반드시 포함 4) 결과는 JSON 형식으로 출력
⚙️ 함수형 예시 — 구조를 알려주기
관세율 조회 함수형 · 무역 업무 최적화
입력: {product_name}, {hs_code}, {country} 처리: 해당 국가의 관세율 및 수입 규제 조회 출력: { "관세율": "", "규제사항": [], "수입규제": [], "필요서류": [] }
유형핵심 원리재사용성유연성언제 쓰나요?
서술형 맥락·배경 설명 낮음 높음 처음 질문, 상황 설명이 필요할 때
지침형 단계·규칙 제시 중간 중간 반복 작업, 형식이 정해진 경우
함수형 입출력 정의 높음 낮음 자동화, 일관된 출력이 필요할 때

02 · 제로샷 / 원샷 / 퓨샷 프롬프트
예시 개수에 따라 달라지는 AI 응답 품질
▼
🌱 핵심 원리 AI에게 예시를 많이 줄수록 더 원하는 방향으로 답을 유도할 수 있습니다. 예시 없이 → 1개 → 여러 개 순서로 점점 더 정확해집니다.
🎲 제로샷 (Zero-shot)

예시 없이 바로 지시하는 방식. 간단한 질문이나 AI가 이미 잘 아는 주제에 적합합니다.

강아지에 대해서 설명해주세요
1️⃣ 원샷 (One-shot)

예시를 1개 제공하는 방식. AI가 형식이나 패턴을 파악해서 비슷하게 답합니다.

"배송 늦어서 실망했어요" → 감정: 부정
"이 제품 마음에 들어요" → 감정: ?
🎯 퓨샷 (Few-shot)

예시를 2개 이상 제공하는 방식. 가장 일관된 결과를 이끌어낼 수 있는 강력한 방법입니다.

긍정/부정/중립 3개 예시 → 분류 요청
🏭 무역 HS Code 분류 퓨샷 예시
HS Code 분류 · 퓨샷 프롬프트
HS code를 분류해주세요. 품목: "면으로 만든 남성용 티셔츠" → 6109.10 품목: "폴리에스테르 소재 여성용 블라우스" → 6206.40 품목: "아동용 데님 바지" → 6209.20 품목: "울 혼방 남성 재킷" → ?
💬 감정 분류 퓨샷 예시
감정 분류 · 퓨샷 프롬프트
감정을 분류해주세요 (긍정 / 부정 / 중립) 텍스트: "배송이 너무 늦어서 실망했어요" → 감정: 부정 텍스트: "그냥 평범한 제품이에요" → 감정: 중립 텍스트: "역대급 만족이야" → 감정: 긍정 텍스트: "품질은 좋은데 가격이 비싸요" → 감정: 중립 텍스트: "이 제품 정말 마음에 들어요" → 감정: ?

03 · 페르소나 패턴 (Act as)
AI의 역할을 지정하면 전문가 수준의 답변을 받을 수 있습니다
▼
🌱 핵심 원리 같은 질문이라도 AI에게 '역할'을 주면 완전히 다른 답변이 나옵니다. 변호사에게 물으면 법적 분석, CFO에게 물으면 재무 분석처럼요.
💡 페르소나가 강하고 구체적일수록 → 답변 범위가 좁고 집중도 높아짐 → AI 자원(토큰) 사용이 효율적
🔄 같은 질문, 다른 페르소나 → 다른 답변
질문: "이 계약서 검토해줘."
⚖️ 변호사 페르소나
법적 리스크 중심 분석, 계약 위반 조항 탐색, 법률 용어 해석
💰 CFO 페르소나
재무 조건과 수익성 분석, 비용·결제 조건 리뷰, 현금흐름 영향
🆕 신입사원 페르소나
쉽고 친절한 설명, 전문용어 풀어쓰기, 핵심 내용 요약
✅ 좋은 페르소나의 4가지 요소
페르소나 기본 공식
당신은 [역할]입니다. [경력/배경]을 가지고 있으며... [전문 분야]에 특화되어 있습니다. [말투/태도]로 응답하세요.
🏭 무역·업무 페르소나 실전 예시
관세사 페르소나 · 무역 업무용
당신은 30년 경력의 대한민국 관세사입니다. FTA 협정세율과 원산지 규정의 전문가로, 중소기업 무역 담당자에게 복잡한 내용을 쉽고 실용적으로 설명하는 것이 특기입니다.
코드 비평가 페르소나 · 개발 업무용
당신은 까다로운 시니어 개발자입니다. 코드 리뷰 시 성능, 보안, 가독성을 엄격하게 평가하며 칭찬보다 개선점을 먼저 지적하는 스타일입니다.
멀티 페르소나 · 전략 분석용
다음 3명의 전문가 입장에서 우리 제품의 동남아 수출 전략을 분석해줘. 김부장: 영업 15년, 낙관적, 현장 중심 이박사: 시장조사 전문, 데이터 중심, 신중함 박대표: 스타트업 창업가, 속도 중심, 리스크 감수 각자의 관점에서 찬반 의견을 제시해줘.

04 · 마크다운을 이용한 프롬프트 작성법
구조화된 프롬프트로 더 정확하고 일관된 AI 응답 이끌어내기
▼
🌱 왜 마크다운인가요? AI는 텍스트를 구조적으로 분석합니다. 역할·조건·출력 형태를 명확히 구분해 주면, AI가 더 정확하고 일관된 답변을 생성합니다.
📌 마크다운 핵심 6가지 요소
# 헤더
1. 헤더 — 프롬프트의 뼈대
#역할, ##작업, ###출력형식처럼 섹션을 나누면 AI가 각 역할을 명확히 구분합니다.
''' 코드블록
2. 코드블록 — 데이터 격리
AI가 지시문과 데이터를 혼동하지 않도록 입력 데이터를 별도로 감쌉니다.
> 인용문
3. 인용문 — 절대 조건 강조
>반드시 한국어로만 답변하세요처럼 절대 지켜야 할 조건을 강조합니다.
- 목록
4. 목록 — 조건 나열
여러 제약 조건이나 요구 사항을 깔끔하게 나열할 때 사용합니다.
| 표
5. 표 — 입출력 구조 제시
입력과 출력의 예시 형태를 표로 보여주면 AI가 패턴을 파악합니다.
**굵게** *기울임*
6. 강조 — 변수와 중요 표시
**[분석대상]**처럼 변수를 표시하거나 *반드시*처럼 중요 단어를 강조합니다.
🏆 마크다운 풀 구조 예시 — FTA 분석 프롬프트
#역할 당신은 중소기업 수출 컨설턴트입니다. FTA 활용과 원산지 증명 전문가입니다. #작업 아래 수출 품목에 대한 FTA 적용 가능 여부를 분석하세요. ''' 품목명: 스테인레스 주방용품 수출국: 한국 수입국: 베트남 HS code: 0000.00 ''' ##분석기준 - 한아세안FTA 협정세율 적용 여부 - 원산지 결정 기준 충족 여부 - 필요서류 목록 #제약조건 >확실하지 않은 세율은 반드시 "세관 확인 필요"로 표기 #출력형식 """json "FTA_적용": True/False, "협정세율": "", "일반세율": "", "필요서류": [], "주의사항": "" """
💡 기억하세요: #역할 → #작업 → #분석기준 → #제약조건 → #출력형식 순서로 작성하면 어떤 업무에도 적용 가능합니다.

05 · 표현 강도와 우선순위 조절
단어 하나로 AI의 응답 집중도가 달라집니다
▼
🌱 핵심 원리 AI는 글의 강도 차이에 민감합니다. "참고하세요"와 "절대로 포함하세요"는 AI에게 완전히 다른 우선순위로 처리됩니다.
📊 표현 강도 4단계
1단계 권장 가능하면, 되도록, ~하는 편이 좋습니다
2단계 일반 ~하세요, ~해주세요
3단계 강조 반드시, 꼭, 항상
4단계 절대 절대로, 어떤 경우에도, 예외 없이
🔄 강도 비교 예시
1단계 (영어 혼합 가능)
가능하면 한국어로 답변해 주세요.
4단계 (완전 영어 차단)
어떤 경우에도 영어를 사용하지 마세요.
🎯 우선순위 체계 설정
🔴 최우선 절대조건
개인정보 절대 출력하지 않는다 · 사실과 다른 내용을 생성하지 않는다
🟠 중요 일반조건
답변은 500자 이내로 작성 · 전문 용어 사용 시 괄호 안에 설명 추가
🟢 선택 권장조건
가능하면 실제 사례를 포함 · 표나 목록을 활용하면 더 좋다
💡 자주 하는 실수 vs 올바른 표현
❌ 애매한 표현✅ 명확한 표현
자세히 설명해주세요각 항목당 500자 내외로 작성하시오
전문가 수준으로관세사 자격증 기준에 입각하여 작성하시오
보안에 신경 써주세요취약점을 반드시 점검하고 발견 즉시 수정방안을 제시하세요
🎨
06 · 톤(말투) 지정하기
같은 내용도 톤에 따라 완전히 다른 글이 됩니다
▼
🌱 활용 방법 대상 독자에 맞는 톤을 지정하면 임원 보고서, 고객 안내문, SNS 게시글을 각각 알맞은 스타일로 한 번에 생성할 수 있습니다.
🎭 5가지 톤 비교
톤 지정 프롬프트 공식
#입력 [내용] = (여기에 원문 텍스트를 입력) #처리 다음 각각의 톤에 맞춰 [내용] 글을 수정해주세요. 1. 힐링되는 2. 감성적인 3. 따뜻한 4. 로맨틱한 5. 전문적인
📝 업무용 보고서 다중 톤 예시
보고서 섹션별 톤 지정 · 무역·업무 보고서용
아래 내용을 보고서로 작성해주세요. ##요약섹션 임원 보고용: 3줄 이내, 숫자 중심, 공식적 톤 ##본문섹션 실무자용: 단계별 설명, 기술적이고 구체적인 톤 ##결론섹션 전체 독자용: 행동 유도, 긍정적이고 적극적인 톤 """ [여기에 보고할 내용을 입력하세요] """
💬 톤별 결과 미리보기 — 무역 업무 실전 예시
📌 원문 입력 텍스트: "저희는 고객의 수출 성공을 위해 통관부터 물류까지 함께합니다."
🌿 힐링 톤
"처음 수출이라 막막하고 두려우셨죠? 괜찮아요. 통관 서류부터 물류 배송까지, 복잡한 건 저희가 다 안고 갈게요. 당신은 그냥 믿고 맡기셔도 됩니다."
💜 감성 톤

08 · 이용자 페르소나 패턴
답을 받는 사람을 AI에게 알려주어 맞춤형 답변 유도
▼
🌱 페르소나 패턴 vs 이용자 페르소나 차이 페르소나 패턴은 "AI의 역할"을 정의합니다. 이용자 페르소나는 "이 답변을 받는 사람"을 정의합니다. 둘을 함께 쓰면 최강의 맞춤 답변을 받을 수 있습니다.

💼 수출 담당 팀장
실무 적용 방법, 비용·효율 중심, 즉시 활용 가능한 정보
🏦 IT 의사결정자
기술 아키텍처, 보안·확장성, ROI 분석, 도입 검토용 정보

  • 얼마나 긴 답변을 읽을 여유가 있는가?
  • 가장 두려워하는 것과 가장 원하는 것은?
  • 절대 쓰면 안 되는 언어나 표현이 있는가?

10 · 뒤집힌 상호작용 패턴

▼

📌 방법 1 — 질문 먼저, 결과는 나중
방법 1 기본 공식
제가 원하는 결과물은 {목표}입니다. 바로 만들지 말고, 먼저 필요한 정보를 질문해주세요. 모든 정보가 수집된 후 결과물을 작성하세요.
📌 방법 2 — 한 번에 하나씩
방법 2 기본 공식
제가 원하는 결과물은 {목표}입니다. 한 번에 하나의 질문만 하세요. 제가 답하면, 다음 질문으로 넘어가고 충분한 정보가 모이면 결과물을 작성하세요.
🏭 무역 실전 예시
수출 제안서 맞춤 작성

맞춤형 학습 계획서 (한 번에 하나씩)
저는 Python 학습 계획서를 만들고 싶어요. 단, 한 번에 하나의 질문만 하고, 제 답변을 들은 뒤 다음 질문으로 넘어가세요. 5~7개 질문이 끝나면 맞춤형 학습 계획서를 작성해주세요.

11 · 인지 검증자 패턴

▼

복잡한 질문 → AI가 하위 질문 분해 → 각각 검증 → 통합 답변 → 신뢰성 높음

방법 2 기본 공식
{전문 분야} 전문가처럼 이 문제를 다루세요. 확신이 없는 부분은 가정으로 명시하고, 각 판단의 근거를 함께 제시하면서 단계적으로 결론에 도달하세요.
